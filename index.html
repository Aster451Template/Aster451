Aster451 Template

Accessible Styling & Typography for Elegant Responsive Web - 451 Standard

紙のような読みやすさや親しみやすさを、 現代のWebページ向けのスタイルとして再構成するための CSSテーマです。

Aster451について

Aster451 は Accessible Styling & Typography for Elegant Responsive Web - 451 Standard の略称です。

読みやすい文字組み、落ち着いた配色、 適切な余白、レスポンシブなレイアウトを組み合わせ、 特別なデザイン知識がなくても扱いやすい Webページの基礎スタイルを提供します。

「451」は、Ray Bradbury の Fahrenheit 451 に登場する紙というモチーフを、 Web上のタイポグラフィとスタイリングへ 控えめに取り入れたものです。

Aster451そのものは紙を模倣することを目的とせず、 紙媒体が持つ読みやすさや親しみやすさを 現代的なWebデザインへ置き換えることを目的としています。

このテーマは、個人・商用を問わず無料で使用できます。Aster451 Templateのドキュメントページ・ライセンスは以下のボタンから。

使い方

このテーマを aster451.css として保存し、HTMLの <head> から読み込みます。

HTMLから読み込む場合 

<link rel="stylesheet" href="https://aster451.aster451-template.workers.dev/aster451.css">

CSSから読み込む場合 

@import url('https://aster451.aster451-template.workers.dev/aster451.css');

※ URLをそのまま本文に書くときは class="url" を付けると等幅で表示されます。

囲みボックス

補足や注意を書く囲みです。

メモ

FILE No. 451

画像テスト

画像は figure で囲みます。 右寄せは回り込み、 gallery は複数の画像を並べて表示します。

写真: Aster ageratoides.jpg / Author: Juni / Wikimedia Commons / CC BY 2.0

右寄せの画像には、本文が回り込みます。 文章が長くなると、画像の左側に沿って流れます。 Aster451では、このような画像と本文の組み合わせも 自然に扱えることを想定しています。

写真: Aster ageratoides.jpg / Author: Juni / Wikimedia Commons / CC BY 2.0

手元の画像をその場で確認できます (ファイルは送信されません)。 

<input
    type="file"
    id="img-test"
    accept="image/*"
>

<figure class="figure">

    <img
        id="img-preview"
        alt="プレビュー"
        width="400"
        height="300"
    >

    <figcaption id="img-caption">
        未選択
    </figcaption>

</figure>

<script>

const pick = document.getElementById('img-test');

pick.addEventListener('change', () => {

    const f = pick.files[0];

    if (!f) return;

    const img =
        document.getElementById('img-preview');

    img.src = URL.createObjectURL(f);
    img.alt = f.name;

    document.getElementById('img-caption')
        .textContent = f.name;

});

</script>
